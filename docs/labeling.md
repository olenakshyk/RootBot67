# Розмітка кадрів у CVAT

Задача: [#47](https://github.com/olenakshyk/RootBot67/issues/47). Кожен розмічає **20 кадрів**, це ~30 хв.
Усе в браузері, нічого встановлювати не треба.

## 1. Підготовка (один раз, 5 хв)

1. Зареєструйся на <https://app.cvat.ai> (безкоштовно).
2. **Projects → `+` → Create a new project.**
   - Name: `rootbot`
   - У проєкті відкрий **Labels → вкладку Raw**.
   - Встав цей JSON і натисни **Done**:

     ```json
     [
       {"name": "cat_warrior", "type": "any", "attributes": []},
       {"name": "keep", "type": "any", "attributes": []},
       {"name": "eyrie_warrior", "type": "any", "attributes": []},
       {"name": "eyrie_roost", "type": "any", "attributes": []},
       {"name": "alliance_warrior", "type": "any", "attributes": []},
       {"name": "alliance_base", "type": "any", "attributes": []},
       {"name": "alliance_sympathy", "type": "any", "attributes": []}
     ]
     ```

   - **Не змінюй порядок міток.** Він має бути однаковим у всіх, бо від нього залежать номери класів під час експорту.
   - **Submit & Open**.
3. **Tasks → `+` → Create a new task.**
   - Name: `person1` (або `person2`, `person3`)
   - Project: `rootbot`
   - Перетягни свої 20 кадрів (теку `personN` тобі передасть Наталія)
   - **Submit & Open**, потім відкрий **Job #1**.

> ⚠️ **Обов'язково вибери Project: `rootbot`**, інакше в задачі не буде міток.

**Перевірка:** у відкритому Job перейди на вкладку **Labels** праворуч. Там має бути 7 міток (**Items: 7**).

## 2. Розмітка

Щільні купки фігурок наближай **коліщатком миші**, щоб контури не зливалися.

Для **кожної фігурки** на кадрі:

1. Зліва на панелі натисни **AI Tools** (чарівна паличка) → вкладка **Interactors** → **Segment Anything**.
2. Обери мітку (клас) фігурки.
3. **Клікни лівою кнопкою по фігурці** - з'явиться контур. Якщо контур захопив зайве, клікни **правою** по зайвому.
4. Натисни **N**, щоб зберегти фігурку. Наступна фігурка: знову **N** і клік.
5. Перехід до наступного кадру: **F**. Зберігати: **Ctrl+S** (час від часу).

Якщо SAM недоступний (на безкоштовному плані є місячний ліміт): обери інструмент **Polygon**,
клацни 5-6 точок по контуру фігурки, **N**.

## 3. Що як розмічати

| Мітка | Що це |
| --- | --- |
| `cat_warrior` | помаранчевий дерев'яний воїн (котик) |
| `keep` | жетон Keep: круглий коричнево-помаранчевий, з фортецею |
| `eyrie_warrior` | синій дерев'яний воїн |
| `eyrie_roost` | темно-синя квадратна плитка з білою гілкою |
| `alliance_warrior` | зелений дерев'яний воїн |
| `alliance_base` | світло-зелена квадратна плитка |
| `alliance_sympathy` | світло-зелений **круглий** жетон (кулак) |

Правила:

- Розмічай **кожну** таку фігурку, навіть якщо вона стоїть впритул до інших: **одна фігурка = один контур**.
- Частково закрита фігурка: обводь лише видиму частину.
- **Не** розмічай: кубики, карти, квадратні плитки предметів, маркери на треку очок,
  коричневі квадратні будівлі й прості круглі жетони дерева Маркізи (наш бот їх не використовує),
  білі та інші фігурки, яких немає в таблиці.
- Фігурка дуже розмита або менша за ~10 пікселів - пропусти.

## Якщо щось не працює

- **AI Tools і Polygon сірі, Items: 0** → у задачі немає міток. Відкрий задачу й перевір, чи вибрано проєкт `rootbot`.
  Якщо ні, додай мітки через **Labels → Raw** тим самим JSON, потім онови сторінку (**F5**).
- **SAM недоступний** → використовуй **Polygon**, як описано в розділі «Розмітка».

## 4. Експорт

1. **Tasks → твоя задача → Actions → Export task dataset.**
2. Format: **Ultralytics YOLO Segmentation 1.0**, галочку **Save images** не став.
3. Завантаж zip і надішли Наталії.
