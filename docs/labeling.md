# Розмітка кадрів у CVAT

Задача: [#47](https://github.com/olenakshyk/RootBot67/issues/47). Кожен розмічає **20 кадрів**, це ~30 хв.
Усе в браузері, нічого встановлювати не треба.

## 1. Підготовка (один раз, 5 хв)

1. Зареєструйся на <https://app.cvat.ai> (безкоштовно).
2. **Projects → `+` → Create a new project.**
   - Name: `rootbot`
   - У розділі **Labels** натисни **Add label** 5 разів і створи мітки (тип **Polygon**):
     `cat_warrior`, `keep`, `enemy_warrior`, `enemy_building`, `enemy_token`
   - **Submit & Open**.
3. **Tasks → `+` → Create a new task.**
   - Name: `person1` (або `person2`, `person3`)
   - Project: `rootbot`
   - Перетягни свої 20 кадрів (теку `personN` тобі передасть Наталія)
   - **Submit & Open**, потім відкрий **Job #1**.

## 2. Розмітка

Для **кожної фігурки** на кадрі:

1. Зліва на панелі натисни **AI Tools** (чарівна паличка) → вкладка **Interactors** → **Segment Anything**.
2. Обери мітку (клас) фігурки.
3. **Клікни лівою кнопкою по фігурці** - з'явиться контур. Якщо контур захопив зайве, клікни **правою** по зайвому.
4. Натисни **N**, щоб зберегти фігурку. Наступна фігурка: знову **N** і клік.
5. Перехід до наступного кадру: **F**. Зберігати: **Ctrl+S** (час від часу).

Якщо SAM недоступний (на безкоштовному плані є місячний ліміт): обери інструмент **Polygon**,
клацни 5-6 точок по контуру фігурки, **N**.

## 3. Що як розмічати

| Мітка | Що це |
| --- | --- |
| `cat_warrior` | помаранчевий дерев'яний воїн (котик) |
| `keep` | жетон Keep (картонний, з фортецею) |
| `enemy_warrior` | дерев'яний воїн **будь-якого іншого кольору** (синій, зелений, ...), також фігурка Бродяги |
| `enemy_building` | **квадратна** будівля іншої фракції (сині гнізда, зелені бази, ...) |
| `enemy_token` | **круглий** жетон іншої фракції (зелені жетони симпатії, ...) |

Правила:

- Розмічай **кожну** таку фігурку, навіть якщо вона стоїть впритул до інших: **одна фігурка = один контур**.
- Частково закрита фігурка: обводь лише видиму частину.
- **Не** розмічай: кубики, карти, квадратні плитки предметів, маркери на треку очок,
  помаранчеві будівлі й дерев'яні жетони Маркізи (наш бот їх не використовує).
- Фігурка дуже розмита або менша за ~10 пікселів - пропусти.

## 4. Експорт

1. **Tasks → твоя задача → Actions → Export task dataset.**
2. Format: **Ultralytics YOLO Segmentation 1.0**, галочку **Save images** не став.
3. Завантаж zip і надішли Наталії.
