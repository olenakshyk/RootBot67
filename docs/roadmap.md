# Роадмап

Проєкт триває ~7.5 тижнів: **22.10.2026 → 14.12.2026** (дедлайн здачі). Дати орієнтовні.
З **07.12** діє **код-фриз**: нових функцій не додаємо, лише виправляємо баги, тестуємо й готуємо здачу.

## Рішення щодо заліза й обсягу (2026-11-11)

| Питання | Рішення |
| --- | --- |
| Кріплення камери | на фланці, **зверху** над захватом, дивиться вниз ([ADR 0005](decisions/0005-camera-on-arm.md) *(з'явиться з PR про камеру на руці)*) |
| Камера | **Intel RealSense**; RGB з заводськими intrinsics (див. [calibration.md](calibration.md#1-внутрішні-параметри-камери-intrinsics)); глибину поки не використовуємо |
| Захват | паралельний захват з власними пальцями |
| Робот | посередині довгої сторони дошки |
| Калібрувальна мішень | офісна чорно-біла калібрувальна дошка (та, що для продових камер), без ArUco |
| Бот | Механічна Маркіза |
| Доповнення | жодних, лише базова гра + сам бот |
| Хто рухає фігурки людей | люди (зокрема прибирають свої втрати) |
| Взаємодія з людьми | лише через застосунок оператора (Android / браузер): сигнали «хід бота», «карта наказу», «кубики», «карту дано», «кінець гри» ([ADR 0006](decisions/0006-operator-app.md)) |
| Хід бота в коді | Behaviour Tree на `py_trees` ([ADR 0007](decisions/0007-behaviour-tree.md)) |
| Запас котів бота | на планшеті фракції бота, камера знаходить планшет за малюнком |

- [ ] 👁️ Еталони дошки й планшета бота (скан + `make_board_reference.py`), пошук обох за малюнком ([vision.md → V1](vision.md#v1-дошка-й-планшет-бота))

- [ ] 🦾 Hand-eye калібрування камера → фланець і площина дошки, похибка < 1 мм
- [ ] 👁️ Оглядові пози, промінь → точка на столі, ~50–100 розмічених кадрів з камери робота
- [ ] 👁️ Підрахунок фігурок v0 (колір) + координати центрів галявин в `autumn.yaml`
- [ ] 🦾 `Arm`, `XArm`, `MockArm`, `jog_robot.py`

**Демо етапу:** робот за командою з консолі переносить воїна з галявини X на галявину Y,
координати беруться з камери.
